# 同人価格スナップショット候補判定 v0.1

更新日: 2026-10-02 JST

## 目的

同人3ソースで正規化済みの価格4項目について、算術上の整合性だけを純粋関数で再検証する。API通信、DB読み書き、履歴生成、分析、公開への接続は行わない。

対象は `doujin`、`doujin_bl`、`doujin_tl` である。入力は観測日時、現在価格、定価、割引額、割引率だけに限定し、商品ID、タイトル、URL、rawレスポンス、秘密情報を受け取らない。

## 整合性条件

- 金額は0以上の整数とする。
- 現在価格がなければ、定価・割引額・割引率も存在してはならない。
- 定価がなければ、割引額・割引率も存在してはならない。
- 定価は現在価格以上でなければならない。
- 割引額は `定価 - 現在価格` と完全一致しなければならない。
- 定価が0より大きい場合、割引率は既存Normalizerと同じく小数第2位へ丸めた値と完全一致しなければならない。
- 定価が0の場合、割引率は存在してはならない。
- 観測日時はタイムゾーン付きでなければならない。

## 安全境界

整合した結果も `READY_FOR_PRICE_SEMANTICS_REVIEW` に留める。これは次を意味しない。

- 同人ソースにおける各価格フィールドの公式意味が確認済み
- 正規化済み価格履歴の保持が許可済み
- セール、値下がり、価格推移などの分析が許可済み
- 公開表示、affiliate利用、sitemap追加、Production反映が許可済み

`HISTORICAL_NORMALIZED_PRICE_RETENTION` と価格・割引セマンティクスの確認が完了するまで、履歴保持、分析、公開、Publication Gate変更は常に不許可とする。公式回答後も自動昇格せず、COMPLIANCEと公開承認を別途必要とする。
