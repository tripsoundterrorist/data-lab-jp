# FANZA BL電子書籍Compliance確認票 v0.1

更新日: 2026-10-03 JST

## 目的

FANZA電子書籍BLフロアについて、既存の公式回答を自動適用せず、将来の公開判断に必要な追加確認を最小4問へまとめる。

確認票は非送信である。現在進行中の問い合わせ回答を受領・確認した後、回答済み項目を除外してから、03 COMPLIANCEとユーザーが手動送信を判断する。

## 最小確認事項

1. 既存の商品情報API表示・比較利用回答がBLフロアへ適用されるか。タイトル、URL、series、genre、価格、review、発売日、定価に対象外または追加条件があるか。
2. FANZA電子書籍BLフロアの商品メイン画像を表示できるか。サイズ、加工、直リンク、クレジット等の条件があるか。
3. `author`と`manufacture`の公式な意味、および取得名称の表示可否。
4. 既存の保存・更新・削除・価格履歴回答がBLフロアへ適用されるか。sanitized rawと正規化価格履歴の保存期間・削除条件があるか。

## 安全境界

- この確認票を自動送信しない。
- 現在の問い合わせ回答前に追加問い合わせを送信しない。
- 回答済み内容と重複する質問は手動送信前に除外する。
- 商品ID、URL、価格値、rawレスポンス、秘密情報を確認票へ含めない。
- 回答を受領しても自動的にfield rightsやPublication Gateを変更しない。
- Production、affiliate、sitemap、robotsを変更しない。

`READY_FOR_MANUAL_COMPLIANCE_REVIEW`は質問候補がレビュー可能であることだけを表し、送信・Compliance承認・公開許可を表さない。
