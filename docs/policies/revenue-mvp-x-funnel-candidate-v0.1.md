# Revenue MVP X Funnel Candidate v0.1

X投稿候補は`SNS → datalabx.jp`だけを対象とし、FANZA/DMMへの直接リンク、商品画像、メンション、返信、ハッシュタグ、誇張・緊急性表現を生成しない。候補には「DATA LAB独自集計・非公式」と固定UTMを付与する。

Issue #66のSNS論点が全て解決し、厳密なbooleanの人間承認が明示された場合だけ`READY_FOR_MANUAL_POST`候補となる。現在は公式回答待ちのため`PREVIEW_ONLY`であり、投稿処理、予約投稿、API呼出し、自動投稿は行わない。

商品一覧へのリンクはPublic Dataが明示的に利用可能な場合だけ候補にできる。画像、成人向け媒体、直接アフィリエイトリンクはv0.1では常に禁止する。

2026-09-05確認時点のX公式ルールに合わせ、正当で透明なアカウント運用、無許可自動化の禁止、成人向け媒体のセンシティブ表示要件を前提とする。本Gateはさらに保守的に媒体を全面不使用とする。
