# Source-artifact lifecycle evidence audit v0.1

Saved lifecycle receipts may supply only their persisted sanitized facts to the
source-artifact revalidator: exact-item API visibility, the saved affiliate URL
validation boolean, and receipt freshness. A saved positive affiliate boolean
is lifecycle evidence only; it does not request or permit a CTA.

The normal collector's `sort=date` observation does not establish rank or
review semantics, provider ordering, an ordinal position, an update cadence,
or an inventory/sales-stop reason. The revalidator therefore supplies no
source sort, no order-preservation assertion, no sort label, no public order
claim, and no CTA evidence. The existing reduced-surface contract remains
blocked and the integration removes the item from the candidate artifact.

This audit does not change a Publication Gate, production route, D1, API or
collector behavior. Every publication and affiliate eligibility flag remains
false. A later minimal Gate would need an independently reviewed
order-independent reduced-surface contract before artifacts can be included;
rank/review or ordering claims require separate official confirmation.
