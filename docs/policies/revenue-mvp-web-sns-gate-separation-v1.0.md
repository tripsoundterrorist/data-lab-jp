# Revenue MVP Web/SNS Gate Separation v1.0

The Revenue MVP release decision applies to the approved production website
`datalabx.jp`. SNS approval and SNS operating conditions are reported through
separate `sns_reason_codes` and `sns_next_actions` fields and cannot block an
otherwise eligible Web release.

Core DMM/FANZA conditions, publication readiness, production smoke, Search
Console readiness, affiliate route deployment readiness, and the connected
server-side affiliate runtime remain mandatory for Web release review.

The DATA LAB X account remains fail-closed until its separate site approval and
all SNS conditions are verified. Until then, the SNS path cannot use affiliate
links, DMM/FANZA product media, or automated affiliate promotion. Ordinary
account-development posts do not change either Gate.

Separation does not authorize deployment, publication, affiliate activation,
SNS operation, or a billing change. Final Web release still requires a distinct
explicit approval after every Web prerequisite passes.
