# 写真集Compliance確認票 v0.1

更新日: 2026-10-02 JST

## 目的

`DMM.com / ebook / photo / photo_book`について、既存の公式回答を自動適用せず、将来の公開判断に必要な追加確認を最小4問へまとめる。

確認票は非送信であり、送信前に03 COMPLIANCEとユーザーの明示的承認を必要とする。

2026年10月6日に手動送信済みのBOOKS次回問い合わせ（電子コミックの残件とFANZA電子書籍BL固有事項）への公式回答を受領・レビューするまで、写真集問い合わせの送信を保留する。回答内容を確認して質問の重複や不要項目を整理した後、改めて手動送信を判断する。

## 最小確認事項

1. 既存の商品情報API表示・比較利用回答が写真集へ適用されるか。title、商品URL、series、genre、現在価格、review数値、発売日、定価に対象外・追加条件があるか。
2. 過去回答で使用しない整理となったDMM Books商品画像について、写真集API画像も表示不可という理解で相違ないか。表示可能な範囲がある場合の対象・サイズ・加工・リンク・クレジット条件。
3. `actor`、`author`、`manufacture`の正式な意味と、人物・著者・提供元等の項目としての表示可否。
4. 既存の保存・更新・削除・価格履歴回答が写真集へ適用されるか。sanitized rawと正規化価格履歴の保存期間・削除条件。

## 安全境界

- 問い合わせは自動送信しない。
- 明示的な公式回答が更新するまでDMM Books商品画像の禁止を維持する。
- 既存回答から写真集scopeを推測しない。
- 回答受領だけでfield rightsや公開Gateを自動解除しない。
- 商品名、URL、画像URL、価格値、raw response、秘密情報を確認票へ含めない。
- Production、Publication Gate、affiliate、sitemap、robotsを変更しない。

`READY_FOR_MANUAL_COMPLIANCE_REVIEW`は文面の手動レビューが可能な状態だけを示し、送信・Compliance承認・公開許可を示さない。
