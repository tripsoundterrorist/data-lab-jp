# DMM/FANZAコンテンツ対象範囲 v0.1

更新日: 2026-10-02 JST

## 決定

DATA LABがDMM/FANZA内で公開準備を進める対象を、当面次の3領域へ限定する。

- 動画
- 同人（通常、BL、TL）
- BOOKS（コミック、BL、TL、小説、写真集）

順番は固定しない。各カテゴリの公式回答、field rights、Compliance判断、技術準備、計測結果、ユーザー承認を満たした時点で個別に公開判断する。

## 境界

DMM BOOKSとFANZA BOOKSは、同じBOOKS表示群でもsource、ドメイン、報酬カテゴリ、画像権利、公開可能範囲を分離して管理する。公式根拠なくentity、権利判断、affiliate条件を相互適用しない。

PCゲーム、通販、オンラインゲーム、くじ、ライブチャット、オンクレ、月額サービスは、現在のcollection-only収集を壊さない範囲で維持できるが、公開準備、UI、affiliate、sitemap、SEOページ追加の対象外とする。

将来これらを再評価する場合は、動画・同人・BOOKSの公開後に得た実測のCTR、CVR、EPC、収益、SEO需要、運用費用を基準にする。

## 根拠と制約

2026-10-02 JSTの公式アフィリエイト画面では、動画、FANZAブックス、同人におすすめ商品と検索キーワード情報が提供されていた。報酬料率にも差があるが、料率は変更される場合があるため、恒久値として実装へ固定しない。

この方針はカテゴリの公開、Compliance承認、affiliate有効化を意味しない。次を維持する。

- 公開中の100商品Revenue MVPと正式計測をP0とする。
- 新カテゴリは確認完了までcollection-onlyかつfail-closedとする。
- 公式回答を別source、別floorへ自動適用しない。
- Production、Publication Gate、D1、robots、sitemapを変更しない。
- 公開とaffiliate接続には03 COMPLIANCE判断とユーザー承認を別途必要とする。
