# 同人ライフサイクル候補判定 v0.1

更新日: 2026-10-02 JST

## 目的

既存の公式回答に基づく商品ライフサイクル判定を、同人3ソースの将来収集へ再利用できるかを安全に検証する。これは収集準備だけであり、同人商品の公開、アフィリエイト導線、Production、Publication Gateを変更しない。

## 対象

- `doujin`
- `doujin_bl`
- `doujin_tl`

入力は正規化済みの観測状態、観測日時、商品ID一致の有無、アフィリエイトリンク存在の有無、在庫シグナル、理由コードだけに限定する。raw APIレスポンス、商品ID、URL、タイトル、認証情報は受け取らない。

## 判定

- APIで商品が返らない場合は公開・アフィリエイトの対象外にする。
- アフィリエイトリンクが存在しない、または不明な場合は対象外にする。
- rate limitまたはAPIエラーは一時停止とし、既存方針の上限（再試行1回、待機最大300秒）を超えない。
- 予約または在庫なしというシグナルだけでは除外しない。
- API表示とアフィリエイトリンクを確認できても、結果は `READY_FOR_EXACT_DOUJIN_SCOPE_REVIEW` に留める。

## 未確認事項と安全境界

DMMへの追加確認事項 `DOUJIN_SOURCE_SCOPE_APPLICABILITY` が未回答である。このため、技術的なライフサイクル候補であっても次は常に `false` とする。

- 同人ソースへの公式適用範囲確認
- 公開候補
- アフィリエイト候補
- 内部履歴保持許可
- Publication Gate変更許可

この判定はAPI呼び出し、DB書き込み、HTML生成、sitemap追加、外部送信を行わない。公式回答後も自動昇格せず、COMPLIANCE再判定と明示的な公開承認を別途必要とする。
