# 同人価格スナップショット集計監査 v0.1

更新日: 2026-10-02 JST

## 目的

隔離されたカテゴリ収集DBの同人3ソースについて、各商品の最新スナップショットへ価格候補判定を読み取り専用で適用する。出力はカテゴリ別の件数だけとし、商品ID、タイトル、URL、価格値、割引値、rawデータを出力しない。

監査前に既存のカテゴリ収集健全性判定が `HEALTHY` であることを必須とする。DBはSQLite read-only modeで開き、書き込みや成果物生成は行わない。

## 集計項目

- 最新スナップショット件数
- 価格構造整合件数
- 価格構造ブロック件数
- 現在価格候補件数
- 割引候補件数
- 価格欠損件数

これらは収集構造の監査値であり、価格意味、セール状態、値下がり、商品価値、公開適格性を表さない。

## 安全境界

監査が成功しても、結果は `READY_FOR_PRICE_SEMANTICS_REVIEW` に留める。正規化済み価格履歴の保持、分析、公開表示、affiliate利用、Production反映、Publication Gate変更はすべて不許可のままとする。

価格構造ブロックが存在しても商品情報は出力しない。修正は自動実行せず、Collectorと実レスポンスの個別監査を別途必要とする。
