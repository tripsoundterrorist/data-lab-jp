# Doujin compliance questionnaire v0.1

This is a review-ready draft only. It does not authorize sending a support
request. `scripts/doujin_compliance_questionnaire.py` routes every fixed handoff
question to either DMM Affiliate Support review or DATA LAB internal COMPLIANCE
review.

Before contacting support, 03 COMPLIANCE must compare each question marked as a
prior-evidence candidate with the exact earlier question and official response.
Reuse is allowed only when the earlier evidence clearly covers the same FANZA
doujin source and requested use. Ambiguous scope stays unresolved; it must not
be inferred from API availability or from a general product-data statement.

Observation-time wording and freshness thresholds are internal policy choices,
not questions for DMM support. Keeping them internal reduces unnecessary
external questions while preserving the requirement not to present a DATA LAB
observation time as an official update time.

Any remaining DMM questions must be manually reviewed, minimized, and approved
before external submission. This questionnaire neither sends a message nor
changes COMPLIANCE, Publication Gate, affiliate activation, sitemap, or
Production state.
